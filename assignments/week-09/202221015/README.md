- 단어 TF-IDF와 문자 2-4 gram TF-IDF 비교, 학습된 밀집 검색기와 구분
- 모델: `Qwen/Qwen3-0.6B-Base`, CPU float32, seed 0, 스레드 2개
- 모델/토크나이저 revision: `da87bfb608c14b7cf20ba1ce41287e8de496c0cd`
- 문맥 600자, 입력 최대 768토큰, 출력 최대 32토큰, 샘플링 없음
- 기존 풀이의 누락 패키지 확인, 체크포인트 고정, 실행 조건/입력 해시 기록 유지
- 2026-10-14 결과와 색인 입력 해시, 검색 후보/근거, 생성 답변, 실제 입력 토큰 ID 해시의 일치 확인
- 생성 시간은 이번 실행의 실측값으로 갱신, 반복 측정이나 속도 우위 검증과 구분

□ 질문별 관찰과 실패 원인

| 질문 | 단어 검색 기준선 | 문자 검색 교체 | 해석 |
|---|---|---|---|
| 한라산 | D019 기후 문장 선택 | D016 지형 문장 선택 | 질문 속성 미지정으로 엄격한 정답 기준 미확정, 두 조건 모두 생성 미실시 |
| 한라산의 높이 | 후보 0개, 생성 생략 | 후보 5개, D018 동물 문장 전달, 모델 출력에 `1000m` 포함 | 색인한 58개 문단 안의 직접 높이 근거 미발견, 후보 증가를 정답 개선으로 판정 불가. 전달 문맥에 없는 수치 생성 |
| 제주도의 기후 | D019 기후 문장 전달, 일부 근거와 일치하지만 32토큰에서 미완성 | 후보에 D019가 있어도 D011 역사 문장 전달, 근거 밖 기후 설명 생성 | 후보 확보 이후 재순위/문장 선택 실패, 최종 모델 입력 확인의 필요 |
| 제주 관광지 오늘 운영 시간 | D047 세계유산 문장 선택 | D025 관광 제도 문장 선택 | 정적 개요에서 특정 관광지의 현재 운영 시간 확인 불가, 두 조건 모두 생성 미실시 |

- 높이 질문의 문자열 포함 proxy는 False에서 True로 변화, 높이를 뒷받침하는 근거 확보와 구분
- 기후 질문의 proxy는 두 조건 모두 True, 관련 후보의 존재와 실제 전달된 문장 사이의 차이
- 생성한 `1000m`는 정답으로 정정하거나 사실로 채택하지 않고 실제 실패 출력 그대로 보존
- 위 실패 사례에서 입력 절단은 발생하지 않은 관찰, 출력 32토큰 제한에 따른 미완성과 별도 분류
- `human_labels`의 사람 판정은 미수신 상태 유지, AI 원문 대조 기록은 `assisted_source_review`에 별도 보존

| 원인 | 개선안 | 개선 여부의 확인 기준 |

| 기후 후보 D019 대신 역사 문장 선택 | 질문 속성과 문장 관련성을 점검하는 선택 기준 검토 | 같은 조건에서 기후를 직접 설명하는 문장이 실제 입력으로 전달되는지 확인 |
| 무관한 근거에서 근거 밖 답변 생성 | 근거 부족 시 응답 유보 여부 검증 | 무관한 근거에서는 유보, 관련 근거에서는 지지되는 사실만 출력하는지 확인 |
