## 측정과 해석

- 1주차: 문자 위치를 입력으로 쓰는 미학습 단일 head. 점수표 저장 바이트와 MAC 계산, 실제 CPU 시간, 가정 단가 비용 분리. 전체 peak 메모리·GPU 시간·실제 청구액 미측정
- 3주차: 원문 문단을 나눠 만든 교수 규칙의 proxy label. 실제 감성 정답·서비스 품질 지표가 아님. 전체 미세조정은 파라미터 기준만 계산, 시간·정확도·peak 미측정
- 4주차: 기존 B/C 입력에 지시문과 서식이 함께 바뀌므로 서식 효과의 인과 추정 불가
- 7주차: 기존 그림은 정답 문자열 포함률, L은 문장별 토큰 수 합의 예산, 깊이는 문장 위치 비율. 새 숫자 일치 지표도 부정문 의미를 판정하지 못함
- 10주차: 실제 base/post-trained checkpoint의 raw continuation 비교. 동일 입력 토큰과 종료 조건 대조. 학습 데이터·훈련 차이가 있어 정렬만의 인과 효과로 해석 불가
- 기존 실측 그림에 새 지표의 수치를 덧씌우지 않음. 실행 환경이 바뀐 지연 값을 기존 그림의 정확한 재현으로 보고하지 않음

## 자료 접근의 한계

- AI Hub 제주 원본: 공식 설명의 `utterance`, `dialect_form`, `standard_form` schema 확인. 인증 후 내려받은 실제 원본 처리 미검증. 원본 없음은 실무 실측 미실행으로 표시
- 제주 포털: 관광 포털 CSV 메타데이터 페이지는 확인했으나 실제 파일·필드·이용 조건 미확인. 직접 조회에서 Python 인증서 오류와 curl HTTP 403 관찰. 데이터허브 초기 페이지 접근은 데이터 확보 증거가 아님
- 9주차: 교수 준비 CSV/JSON 어댑터와 검색 비교 골격 제공. 실제 포털 파일 없는 기본 상태는 미수집, 검증 실패는 미확인. 두 포털 색인 과제 전체 완료·포털 생성 평가 완료로 보고하지 않음
- 임시 schema 검사 입력은 검증용 교육 자료이며 실제 공개 데이터로 저장하거나 커밋하지 않음
- 무료 Colab 화면 자체의 실행은 미검증. CPU 검증은 로컬 격리 Python 환경, 새 커널, 설치 셀 포함 실행 기준
